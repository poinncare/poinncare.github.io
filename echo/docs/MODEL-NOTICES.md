# Модели в релизе Echo

Файлы скопированы без изменения из подготовленных GGUF-конверсий. Исходные разработчики и условия моделей:

- NVIDIA Parakeet TDT 0.6b v3: NVIDIA, CC BY 4.0.
- NVIDIA Nemotron 3.5 ASR Streaming 0.6b: NVIDIA, лицензия OpenMDW 1.1.
- NVIDIA diar_streaming_sortformer_4spk-v2: NVIDIA, CC BY 4.0.
- Parakeet Hebrew: адаптация thewh1teagle/parakeet-tdt-0.6b-v3-he, CC BY 4.0; авторство сохранено в карточке модели.

Оригинальные карточки и лицензии моделей приложены отдельно рядом с файлами в релизе. Названия моделей используются для указания совместимости; Echo не является продуктом NVIDIA.
