# Каталог моделей Echo

Echo показывает встроенный каталог сразу, затем раз в сутки обнаруживает новые
совместимые модели и варианты сжатия в публичных источниках Hugging Face. На
момент подготовки каталога: 15 моделей, 42 файла, четыре семейства — Whisper
(включая Distil-Whisper), GigaAM, Parakeet и Nemotron. При недоступности сети
остаётся последний сохранённый каталог. После частичного сбоя проверка повторяется
не чаще раза в час; установленные веса никогда не заменяются в фоне.

## Как выбираются модели

Обнаружение использует список репозиториев издателя `handy-computer`, репозиторий
`ggerganov/whisper.cpp` и публичные GGML-экспорты `distil-whisper` / `ivrit-ai`
с метаданными ASR. Это запросы к живым спискам издателей, а не перечень имён
известных сегодня моделей. Из неполной карточки без подтверждения формата и
назначения модель в список не попадает.

До предложения GGUF-файла Echo читает только его заголовок (не более 2 МиБ),
проверяет архитектуру, вариант, тип декодера, языки и необходимые имена тензоров.
Whisper проверяется по GGML-заголовку. Сервер, игнорирующий Range-запросы,
пропускается: ради обнаружения нельзя скачивать многогигабайтные веса.
URL фиксируется на SHA ревизии, каждому файлу сохраняются размер и SHA-256.
Новые файлы и совместимые адаптации появляются без выпуска Echo. Совершенно
новая архитектура требует добавления движка и обновления приложения.

Для длинных файлов все предлагаемые движки используют обработку ограниченных
фрагментов и временные отметки: Whisper обрабатывает свои окна; GigaAM,
Parakeet и Nemotron используют Silero VAD. Дополнительный VAD устанавливается
автоматически вместе с выбором такой модели из каталога. Возможность обработки
файлов не определяется наличием у исходной модели режима мгновенной диктовки.

Для слабых ноутбуков по умолчанию выбраны компактные варианты Q5, а полные F16
и другие поддерживаемые варианты доступны в той же карточке. F32 не предлагается:
для этой аудитории почти двукратный размер и память не оправданы. Старые Whisper
large-v1/v2 исключены из обнаружения при наличии large-v3; tiny/base/small/medium
сохраняются как разные уровни потребления памяти, а не как рекомендации по возрасту.

Стартовый экран показывает GigaAM для русского и компактный Whisper для широкого
набора языков; «Все модели» открывает весь каталог. В настройках есть поиск,
фильтры семейства и языка, выбор сжатия, загрузка и удаление. Скачанные варианты
отмечаются по имени файла; другие варианты той же модели остаются доступными.

Рекомендация GigaAM сохраняется для русской речи. Для других семейств алгоритм
выбирает по одному русскоязычному/многоязычному варианту меньше 1 ГиБ, используя
сопоставимые публичные оценки: 70% вес точности, 30% вес скорости на CPU.
Новая совместимая модель с лучшими измерениями может занять рекомендацию
автоматически. Возраст и популярность сами по себе не означают лучшее качество.

Полоски строятся из данных карточек `transcribe_cpp`: WER FLEURS Russian для
моделей русского языка, FLEURS English для английских, throughput CPU Ryzen 7
4750U. Шкалы: `accuracy = 100 * exp(-WER / 15)`,
`speed = 100 * (1 - exp(-throughput / 8))`. Это сравнительные оценки базовых
моделей Q8_0 в исходном runtime, **не проценты распознанных слов и не замеры Echo**.
Источник, набор данных и оборудование видны при наведении. Для моделей без
сопоставимых измерений отображается отсутствие данных; оценки не выдумываются.

Публичный каталог, доступный без входа в GitHub:
https://gist.github.com/poinncare/dca237ff9a29684c6c7a2de7a57a08d8

Исходник офлайн-каталога: `desktop/src/lib/model-catalog-data.json`.
Воспроизводимое обновление использует тот же код обнаружения, что и приложение:

```sh
cd desktop && pnpm dlx tsx scripts/refresh-model-catalog.ts
cd ..
uv run scripts/publish_model_catalog.py --check
uv run scripts/publish_model_catalog.py
```

Публичный JSON дополняет обнаружение и даёт новые предложения старым клиентам.
Сбой одного издателя или более старый JSON не скрывает модели из сохранённого
каталога. Эти команды нужны для подготовки офлайн-снимка к сборке; установленное
приложение обновляет список самостоятельно, без кнопки и действий пользователя.

GigaAM v3 E2E RNNT INT8 скачивается из публичных репозиториев
`istupakov/gigaam-v3-onnx` и `ai-sage/GigaAM-v3` на Hugging Face. Echo проверяет
хеши четырёх компонентов и объединяет их в локальный контейнер `.gigaam`.
Python, GitHub CLI и вход в аккаунт пользователю не нужны. Состав ONNX-пакета
GigaAM закреплён в native downloader: изменение его схемы требует обновления Echo.
Предыдущие `.gigaam`
модели остаются совместимыми. Преобразование ONNX с INT8 проверено на эталонной
русской записи, обработке длинного аудио, тишине и отмене.

Публичные Parakeet v3 / Nemotron 3.5 Q5_K_M проверены установленным echo-server
на русской записи, записи с несколькими VAD-фрагментами и на тишине. Это проверка
совместимости, а не измерение точности на пользовательских многочасовых записях.

# Обновления приложения

Echo проверяет подписанные обновления при запуске и затем раз в сутки, загружает
установщик в фоне и проверяет подпись. Установка и перезапуск происходят после
подтверждения пользователя. Каталог моделей обновляется независимо.

Сборки внутри релиза `v1.0.0` различаются маркером `echo-build` в `latest.json`.
Workflow Release добавляет его после сборки всех платформ, сохраняя версию,
URL и подписи платформ. Для ручной публикации метаданных:

```sh
uv run scripts/stamp_update_manifest.py latest.json --commit <полный SHA коммита>
```

Репозиторий Echo сейчас закрыт. Перед публичным распространением приложения
подписанные установщики и `latest.json` должны быть доступны без авторизации:
либо через публичные релизы Echo, либо через отдельное публичное хранилище с
соответствующей заменой endpoint в `tauri.conf.json`. Учётные данные разработчика
не должны распространяться внутри приложения. Публикация публичного каталога
уже выполнена; публикация установщиков этой локальной задачи не требуется.
