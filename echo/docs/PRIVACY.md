# Конфиденциальность Echo

Echo обрабатывает аудио и видео локально. Файлы и расшифровки сохраняются на вашем устройстве. Для локальной транскрибации не требуется отправлять запись во внешний сервис.

Сетевые запросы используются для загрузки моделей, обновлений и контента по введённой вами ссылке. Если вы подключаете Claude, запись не отправляется, но текст расшифровки передаётся выбранному сервису для анализа. Ollama работает по указанному вами адресу. Запись с телефона передаётся компьютеру через защищённое соединение.

В Echo не настроены ключи аналитики исходного проекта. Не вводите секретные данные в отчёты об ошибках; просмотрите журнал перед его отправкой.

Вопросы и сообщения об ошибках: [Echo Issues](https://github.com/poinncare/Echo/issues).
